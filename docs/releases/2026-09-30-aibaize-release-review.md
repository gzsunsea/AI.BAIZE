## 本轮更新

### 热点事件与内容质量

- 改进事件身份与去重逻辑，综合规范化 URL、标题指纹及事件线索，减少同一事件被拆成多条或不相关报道被合并的情况。
- 热点页和事件详情提供事件生命周期、来源时间线和相关候选；候选与已确认来源分开呈现，不把待核实内容冒充确认信息。
- 调整精选排序及事件代表稿选择，体现一手来源、专家来源和可验证的独立报道，同时保留来源覆盖信息。

### 报告头版主稿

- 日报、周报、月报新增自动选择的 `coverStory`，候选仅取报告最终展示的条目；保留原有期刊标题、栏目顺序和条目列表。
- 有可用图片时仅显示主稿自身图片，并通过现有 `/api/media` 安全代理加载；无图或加载失败时回退为文字主稿。
- REST 和只读 MCP 的报告投影都显式序列化主稿字段，旧客户端遇到字段缺失或空值仍可使用原报告布局。

### 可选本地视觉增强

- Ollama 视觉增强由 `OLLAMA_VISION_MODEL` 显式启用；未配置时维持文本摘要流程。
- 仅对优先 X、一手官方及专家 RSS 条目尝试最多一张 JPEG、PNG 或 WebP 图片，单图上限 2 MiB；媒体获取或视觉推理失败时回退文本流程。
- 公共媒体抓取保留 DNS 解析校验、IP 固定、逐跳重定向复核和响应大小限制。

### 只读 MCP 接口

- 新增默认关闭的 `/mcp`，提供五个只读工具：精选流、搜索、热点、事件时间线和日报/周报/月报。
- 工具输入、结果大小、请求体、Host/Origin 和请求频率均有边界控制；没有后台、配置或写入工具。
- **生产环境仍未启用 MCP**：部署后 `/mcp` 返回 404。启用前需由运维方配置明确的 Host/Origin 白名单并单独完成暴露面审查。

## 过程复盘

1. **SSH 失败原因在本地调用，不在服务器配置。** 初次尝试没有显式指定部署专用 SSH 身份；使用正确身份后以 root 登录成功。全程没有修改服务器认证配置。
2. **测试夹具混用了两套时钟。** 一项“今日信号”测试固定在 9 月 27 日，而评分器按实际系统时间重算时效分，导致合格样本被过滤。将测试发布时间改为相对当前时间后，测试通过；没有放宽门槛或改动线上评分规则。
3. **依赖审计必须纳入发布门槛。** 初次生产依赖检查发现 high 级漏洞，因此先检查兼容修复、更新 lockfile 并重跑安装、测试、类型检查和构建，再进行生产切换。
4. **运行数据与代码回滚必须分开。** 通过非删除式同步并排除 `data/` 保留线上数据；回滚材料仅覆盖代码与依赖，不承诺恢复数据库历史。
5. **凭据输出需要脱敏。** 只读查看 systemd 单元时，诊断输出曾包含内联管理令牌。本说明不记录令牌值；本轮没有轮换该令牌。应将其按可能暴露处理，在单独受控的配置变更中轮换并验证后台访问；后续检查避免直接输出 `Environment` 内容。
